# hamsung-assets

함성파트너스 공개 자료(GitHub Pages · https://hamsungpartners.github.io/hamsung-assets/)

| 경로 | 내용 |
|---|---|
| `proposal/` | 통합제안서(서비스 · 가격표 · 3분 견적) · '이 견적으로 접수하기' → 홈페이지 `/quote` |
| `intro/` | 옛 견적설계제안서 주소 · 통합제안서로 넘김 |
| `ig-guide/` | 고객용 인스타그램 · 스레드 권한 부여 가이드 |
| `site/` | 홈페이지(hamsungpartners.com · 아임웹) 코드 위젯 원본(`home-widget.html` · `quote-widget.html`)과 그림(`img/`) · 영상(`media/`) |

- 공개 저장소다. `git add .`는 쓰지 않고 바꾼 파일만 골라 올린다.
- `site/*-widget.html`은 아임웹 코드 위젯에 그대로 넣는 반영본이다. 원본과 빌드는 함성 맥 `web/hamsung-homepage/`(build_imweb.py)에 있다.
